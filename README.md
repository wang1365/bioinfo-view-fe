# 纳昂达临床解读系统

### 技术架构
- 前端应用框架：`vue3` - https://v3.cn.vuejs.org/
- UI框架：`quasar2` - https://quasar.dev/


### 安装依赖
> 说明：node版本须大于14
```bash
yarn
# or
npm install
```

### 开发模式启动应用
```bash
quasar dev
```


### lint检查文件
```bash
yarn lint
# or
npm run lint
```


### 文件格式化
```bash
yarn format
# or
npm run format
```



### 生产环境产品构建
### Build the app for production
```bash
quasar build
```
